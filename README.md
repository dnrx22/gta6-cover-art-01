Neon Vice Cover Studio is an offline web app that turns your own photo and caption into a multi-panel poster in the style of a Vice City sunset: pick up to three photos, crop and position each panel, choose a sunset, neon or noir colour grade, type your own bold title and tagline, then export the finished cover as a PNG in 1080x1080, 1080x1350 or 1920x1080. Everything runs locally in the browser with no network calls and no uploads.

## Run it
```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
